# RainLock Privacy Policy

This repository contains the public privacy policy for RainLock.

- Privacy policy: [PRIVACY_POLICY.md](PRIVACY_POLICY.md)
- Web version: https://sudarshanchaudhari.github.io/rainlock-privacy-policy/
- Contact: sunny.sudarshan@gmail.com

## The one thing not to lose from this policy

RainLock transmits the user's coordinates to **OpenWeatherMap** (`api.openweathermap.org`) when weather-based auto-enable is switched on. That is the app's only outbound request, and it is a transfer of location data to a named third party. Any future edit must keep that disclosure, name the recipient, and keep the Play data safety table marking location as shared.

## Editing

`PRIVACY_POLICY.md` is the source of truth. `index.html` carries the same content for GitHub Pages and must be updated in the same commit — Pages serves `main` at the repository root with no build step, so a change to the Markdown alone does not reach the published page.

This README no longer duplicates the policy text. It used to, which left three copies of the same document drifting apart.
